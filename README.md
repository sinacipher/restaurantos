# RestaurantOS

A multi-tenant restaurant management and commerce SaaS platform. 

## Tech Stack
- **Frontend**: React 19, Vite, TypeScript, Tailwind CSS v4, TanStack Query, Zustand, React Router, Recharts, Lucide Icons, Sonner.
- **Backend**: Node.js, Express 5, TypeScript (via `tsx`), Vercel Function architecture.
- **Database**: Neon Serverless PostgreSQL, Drizzle ORM.
- **Integrations**: Better Auth, Stripe (Test), Ably (Real-time), Cloudinary (Images), Resend (Email).

## Prerequisites
- Node.js v20+
- Windows 11 / CMD
- Vercel CLI (`npm install -g vercel`)
